# Frozen v3 static baseline

This folder preserves the exact public v3 static prototype that existed before
the React + TypeScript rebuild.

- `index.html` is an unmodified byte-for-byte copy of the original root page.
- `preview.png` is an unmodified byte-for-byte copy of the original preview.
- These files are historical reference material and are not part of the live
  Vite application.

Do not edit these two baseline files. The root application is the maintainable
demo that replaced them.
